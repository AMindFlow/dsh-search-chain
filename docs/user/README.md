# 用户文档

本目录面向安装和使用 dsh-search-chain 的用户。内容以 `main` 的现行实现为准；与开发规格（`docs/specs/draft/`）不一致的地方，以本目录为准描述实际行为。

- [快速开始](getting-started.md)：安装与启用、配置条目的字段含义、凭据来源与优先级、DeepSeek 官方分支、`maxResults` 语义，以及当前已知限制。
- [排错指南](troubleshooting.md)：按错误码查看现象和可操作的处理办法，并说明如何读取 `details.attempts`。
- [升级指南](upgrade.md)：从 0.x 开发版升级到本版时的变化、影响和手动检查清单。
- [项目文档](../README.md)：规格、路线图和开发协作规则（面向维护者）。
