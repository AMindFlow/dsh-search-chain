# 设置面板 v3 用户反馈修订（定稿）

来源：用户实机观感反馈（PR #51 演示实例，2026-11-26 07:39 +08:00，三项）。本修订与 `settings-panel-style-lock-v2.md`、`settings-ui-save-granularity-amendment.md` 冲突处以本文为准；目录断言由 Luna 按 §3 增量勘定（唯一判据权威不变，用户指令为规格源头）。

## V3-1 新建文案统一「保存」+ 未提交新建不入列
1. 编辑器提交钮文案统一：编辑与新建均为 `取消 | 保存`，busy=`保存中…`。**废止 `创建工具`/`创建中…`**（任何编辑器动作标签中不得出现）。SET-007 成功提示语义不变（`已保存 ${名称}。` 同样覆盖新建场景）。
2. **未提交的新建条目不得出现在上方列表**：打开新建编辑器（含 O-6 自动重开、后台读回后的缓存复原）仅呈现编辑器，列表恒等于已持久条目视图。废止 v2 的「未提交新建重追加尾部」overlay 分支（create 模式）；edit 模式的活动行 overlay 与全量草稿复原（V 轮 P2#4 修复）保持——复原语义=编辑器字段复原+自动重开，不是列表占位行。
3. 校验/绑定守卫对新创语义不变（新建候选=有效列表+1 行末尾，仅存在于提交载荷，不落页内视图）。

## V3-2 把手几何收紧（精确值裁定）

| `.sc-drag-handle` height | 28px | 28px（纵向触控区不减） |

显隐/过渡/焦点/disabled 规则、hover 层、dragging 语义零改动（R3 其余条款不动）。

## V3-3 开关类操作不再发成功文案提示
- **不再触发 savedNotice 的动作**：条目启用开关（开/关）、官方搜索开关（开/关）。开关本身的状态呈现即为反馈；持久化仍即时（SET-006 不变）。
- **保留 savedNotice 的动作**：条目编辑器保存（`已保存 ${名称}。`）、超时提交（`已保存设置。`）、删除确认、重排落定（维持现状）。
- savedNotice 槽位/样式/role=status 规范（SET-007）不变——仅收敛触发集。验收执行等待锚点相应由「savedNotice 在场」改为「该动作自身 mutate 完成 + 开关视觉态」。

## §4 目录影响清单（转 Luna 勘定）
- 文案类：A-057（提交钮双态文案）、其他引用 `创建工具/创建中…` 字面处 → 统一保存族；新增/改写：新建编辑器开启时列表行数不变（无占位行）。
