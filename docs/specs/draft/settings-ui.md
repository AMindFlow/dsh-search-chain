# 网页搜索链设置

本规格定义 DSH 设置面板中的搜索工具配置区域。布局参考模型设置的列表和编辑入口，使用宿主主题和设置控件。

## SET-001 设置入口与列表

- **要求** 安装并启用插件后，DSH「设置」必须出现「网页搜索链」区域。区域顶端显示 [SET-005](#set-005-deepseek-官方搜索开关) 的开关。下方由上到下显示可拖动的工具卡片，卡片显示名称、类型、配置状态及启用开关，并提供编辑和移除入口。列表末尾提供「添加搜索工具」。新配置的工具列表为空，空状态引导添加。
- **来源** [用户提供的模型设置截图和新版设置面板要求 R9](../../project/requirements.md)。
- **验收** 从 DSH 设置进入「网页搜索链」。验证空状态、添加入口和首张卡片。切换宿主主题，核对标签、开关和状态可读，且能辨别缺少 key 与已关闭。

## SET-002 增加、编辑与停用

- **要求** 添加工具时必须可选[首期目录](providers.md#cat-001-首期类型)，保存后该条目追加到末尾并启用。用户可单独编辑条目的名称、凭据、适用的模型或模式及网络设置。每个条目有稳定身份，同一种类型可添加多个独立实例。关闭条目须保留它的配置和位置，重新开启后在原位置参与搜索。移除条目只移除此处配置，复用的宿主凭据不得被移除。
- **来源** [用户补充的多条目与停用要求 R9](../../project/requirements.md)。
- **验收** 添加两个相同类型和一个不同类型的工具。编辑其中一条，验证另外两条配置未改变。关闭、重开、移除并重新打开设置，核对对应条目的位置、开关及其余条目。选择 Bing RSS 时编辑器无需填写 key。

## SET-003 拖动调整优先级

- **要求** 用户可用卡片的拖动把手改变列表顺序，键盘也能完成等价的上移和下移。保存后，搜索必须按列表从上到下尝试启用条目。被停用的条目可排序，在网络请求中跳过。结束设置或重启 DSH 后，列表与实际搜索顺序必须一致。
- **来源** [用户补充的拖动排序和自定义 fallback 要求 R6、R9](../../project/requirements.md)。
- **验收** 添加 A、B、C 并停用 B，用拖动保存 `C、B、A`，让 C 的搜索失败，观察请求按 C、A 发送。用键盘把 A 移至第一，复核视觉顺序及后续请求顺序。重启后复查顺序和 B 的停用状态。

## SET-004 保存与凭据状态

- **要求** 设置页必须读写 [CFG-004](config-network.md#cfg-004-配置快照与连接释放) 约定的同一份宿主配置。保存成功后才确认生效。保存失败或配置已被其他界面改动时，保留未提交编辑，向用户显示可操作的错误。条目状态只表示本地配置与启用情况。打开面板、切换开关、排序和保存均不得自动发出供应商请求。
- **来源** [原始需求 R4、R7及新版设置面板要求 R9](../../project/requirements.md)。
- **验收** 用合成 key 修改条目，检查列表只显示凭据状态。注入保存失败或版本冲突，核对错误可见且宿主继续使用已保存快照。对面板操作逐一记录出站请求，供应商请求数须为零。

## SET-005 DeepSeek 官方搜索开关

- **要求** 设置页必须提供「DeepSeek 官方 API 使用官方搜索」开关，默认开启。开关旁写明适用会话、关闭后使用下方工具链，以及官方搜索工具不另按次收费、模型用量仍按 token 计费。开关的路由效果由 [DSH-005](dsh-integration.md#dsh-005-deepseek-官方-api-路由)定义。
- **来源** [用户补充的 DeepSeek 官方 API 搜索开关 R10](../../project/requirements.md)。 [DeepSeek 官方计费](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)
- **验收** 未设开关时显示为开启，切换并保存后重新打开确认状态持久化。用官方 API 和其他模型会话各发一条测试查询，按 DSH-005 核对实际路径。切换期间自定义列表的配置和位置应随保存保持一致。

## 设计决定

- 本机 dsh `0.2.2-rc.5` 的模型页使用 `settings.section` 注册设置区。插件优先通过该插槽挂载自己的区域和原生主题控件。第三方插件亦有以 `plugins.bundle.config` 在内置插件页放置设置区域的先例。WP0 在隔离 profile 实证本包 `settings.section` 注册及保存能力后定案：本包唯一配置入口为设置页区域；详情页 bundle 配置表单已于 #80 退役（历史见 Git）。
- 沿用宿主现有设置表单及其修订检查，以及模型页的凭据保存入口。页面组件只负责编辑和呈现，路由决策归宿主插件。
