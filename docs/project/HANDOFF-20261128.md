## v0.3.0 开工前补充（2026-11-28 深夜，本工作包记忆清仓）

### 发布配方（v0.2.0 实操原版，此前只活在会话记忆里）

1. 版本号 bump 走 PR 合入 main；在 main 合并提交上打**附注** tag：`git tag -a v<X.Y.Z> <main提交>`，推送前必验 `git rev-parse v<X.Y.Z>^{commit}` 解引用一致，再 `git push origin v<X.Y.Z>`。**历史 tag 永不移动**（v0.1.0 `2a066933` / v0.1.1 `0187d45c` / v0.1.2 `3e666160` / v0.1.3 `38a988ff` / v0.1.4 `efe4ad0e` / v0.2.0 `a603a5b8`）。
2. 索引：`INDEX_URL=https://raw.githubusercontent.com/AMindFlow/dsh-plugin-index/main/market-index.json node scripts/make-market-index.mjs` 生成 → 宿主验证器校验（脚本末尾打印的 `ELECTRON_RUN_AS_NODE=1 …parseMarketIndex…` 命令，`DSH_INSTALL_DIR` 指向宿主 app.asar/dsh）→ PUT 前先 `gh api repos/AMindFlow/dsh-plugin-index/contents/market-index.json --jq .sha` 取新鲜 sha，`gh api -X PUT … -f message=… -f content="$(base64 -i artifacts/market-index.json)" -f sha=<新sha>`。
3. npm：`npm pack` → 临时目录解包 → 去 `private`/`devDependencies` → 独立 `.npmrc`（`//registry.npmjs.org/:_authToken=<NPM_TOKEN>`，chmod 600，**用完即删、永不回显**）→ `npm publish --userconfig <该npmrc>`。token 位于 `~/.dsh/.credentials.yaml` 的 `NPM_TOKEN`；能力边界：publish ✅、deprecate ✅、**unpublish ❌**（敏感操作需用户本人 `npm login` 逐次 web 验证）。
4. 渠道同步：官方 Discussion deepseek-ai/deepseek-harness#14418 正文（版本+安装 pin）、dshopen polang233/dsh-plugin-index#830 追评、自建索引按第 2 步替换。awesome 等 #19545 落地后如需再追。
