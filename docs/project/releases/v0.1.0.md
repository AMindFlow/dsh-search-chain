## 交付范围

- 有序搜索链：条目 = 供应商 × 端点，**串行 fallback**（前一个失败或无结果才降级；不是并行聚合）。七类适配器：Bing RSS、Brave、Exa、Gemini、OpenAI、Tavily、DeepSeek（官方分支共存）。
- 设置面板：与「模型」同级同风格；原位新增表单、编辑开关收起、入口互斥、清除按钮。
- 凭据：宿主 credentials 服务存储，GUI 不回显明文。
- 条目级代理出站（#61/#62/#58/#63）：三态配置（直连 / `host:port` 代理 / `pac:` PAC 脚本）；**非对称拒绝**——配了代理的条目只走该代理，永不静默回退直连。
- PAC 沙箱：`vm` 隔离 + `codeGeneration` 禁生码 + 宿主内禀封固（含 `__proto__` 数据属性封）+ 金丝雀自检失败即拒评；内存两层边界——脚本堆 24 MiB 硬限（V8 自爆）+ 父进程 RSS 144 MiB 兜底闸；全局槽位串行求值、墙钟 2 s；远程 PAC 保存时提示内容可被服务器随时更改。
