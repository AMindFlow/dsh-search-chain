# 路线图

首个可发布里程碑暂用 `v0.1.0`。工作包、负责人和进度通过 [GitHub Projects](../workflow/github.md#github-projects)管理。

| 阶段 | 交付 | 完成条件 |
| --- | --- | --- |
| 宿主验证与共享契约 | 在测试 profile 验证设置区域、凭据与有序配置读写、官方 DeepSeek 路由及搜索结果展示接口 | 能从 DSH 设置打开插件区域，用合成数据保存与重读顺序和开关，官方分支有可调用的宿主入口。产出共享请求、结果、配置与测试契约 |
| 首期并行开发 | 实现设置交互、逐条传输、排序执行和七类工具适配 | [SET-001 至 SET-005](../specs/draft/settings-ui.md#set-001-设置入口与列表)的操作可验证。支持任意启用顺序，并覆盖停用、无 key、超时、失败及全部无结果 |
| 宿主装配与发布 | 在真正 DSH 工具中连接设置、官方开关与搜索链，交付候选包和使用说明 | [DSH-004](../specs/draft/dsh-integration.md#dsh-004-热重载与发布验收) 验收通过。Gemini 须完成 [GMI-002](../specs/draft/gemini.md#gmi-002-宿主展示与发布条件) 的展示验证。记录各适配器的实机结果、用量及回退 |
| 后续用量 | 设计 R8 提示 | 根据实际计量数据确定可核对的提示方式 |

Gemini 展示验证与其余适配器开发可以并行。Bing RSS 已用公开查询验证返回格式，候选包还须复查目标网络及错误行为。
