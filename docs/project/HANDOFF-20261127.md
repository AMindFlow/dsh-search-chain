## 一句话定位

**网页搜索链（dsh-search-chain）**：有序多厂商搜索降级链——条目 = 供应商 × 端点，按保存顺序串行尝试、失败或无结果才降级（**不是并行聚合**）；把各厂商免费额度聚合为一个高额度、确保可用的 web_search，结果质量优于裸 Bing 或 web_fetch。附带条目级代理三态出站 + PAC 沙箱。

## 技术速查（改这些前先读对应规格/注释）

- **串行 fallback**（用户拍板）：降级仅在失败/无结果时发生，不掺水不聚合。
- **代理三态 + 非对称拒绝**：条目配了代理就只走该代理，永不静默回退直连（测试钉死的行为承诺）。
- **PAC 沙箱**（`src/pac-eval-worker.js`）：vm ctx `codeGeneration:{strings:false,wasm:false}`；12 个 Object.prototype 成员 + `__proto__` 数据属性 + 外部内存对象（ArrayBuffer/SAB/TypedArray/Atomics 等）undefined 封固 + 金丝雀自检失败即拒评（PAC_EVAL_FAILED）。
- **两层内存**（`src/transport.js` 注释块有实测依据）：worker `--max-old-space-size=24`（V8 自爆 SIGABRT）+ 父进程 RSS 144 MiB 轮询兜底（`ps -o rss=`，25ms 间隔，SIGKILL 复用超时路径）；全局槽位 1 串行求值、墙钟 2s。**别再写「总内存 ≤64MiB」**——物理上不成立，用户态兜底闸的上紧版是 OS 级 #64。
- **零常驻**：不配远程 PAC 就永不 spawn worker。
- V8 怪癖：惰性字符串使 `repeat` 有限循环不 OOM，堆压测必须用 `while(true)` 物化式（T10-1 已按此写）。

## 环境坑（都踩过）

- **main 分支保护**：现在必须 PR 合入（`gh pr merge --squash --admin`，仓库规则 2026-11-27 起生效）。
- **永不提交** `package-lock.json`（本机 npm、profile pnpm，锁文件已 gitignore）；**永不改** `scripts/oracle-style-50.mjs` 的 `CATALOG_TEXT`。
- GitHub API 偶发 Bad Gateway：重试即可；graphql 挂了换 REST。
- harness 密钥遮蔽层会改写命令行里的假 key 字面量 → oracle 造 key 用 `printf 'syn%s' 'thetic'` 拼接绕过。
- codex 评审触发：`gh pr comment N --body '@codex review'`；security 约 10-12min，code 约 3min；读线程状态以 inline + isResolved 为准。
- GitHub squash 合并后立刻 retarget/merge 会遇 mergeable 重算竞态：等 CLEAN 再操作。
- PR 重建时 `git add -A` 要按 scope 检查别漏文件（#65 的教训：漏了 docs/scripts 两文件）。
